Politica de privacidad - AntCashManager

Ultima actualizacion: 16 de mayo de 2026

Version de referencia: Ingles - wiki/privacy-policy.html

Resumen: AntCashManager no recopila datos personales o sensibles mediante analytics personalizados. Solo se recopilan datos de uso de la aplicacion.

1. Datos que recopilamos

Solo se registran eventos tecnicos de uso (por ejemplo, apertura de pantallas y acciones funcionales) para mejorar estabilidad y usabilidad.

2. Datos que NO recopilamos

  • Texto libre introducido por el usuario (busqueda, notas, titulos, descripciones)
  • Datos de transacciones sensibles/de contenido (payee, location, tags, detalles descriptivos de importes)
  • Correos electronicos o identificadores personales directos
  • Mensajes de error en bruto, stack traces o contenido que pueda incluir datos personales

3. Eventos permitidos (usage-only analytics)

  • screen_view (evento estandar de Firebase)
  • transactions_filter_applied
  • transactions_filter_cleared
  • transaction_add_opened
  • receipt_scan_opened
  • transaction_form_opened
  • transaction_form_cancelled
  • transaction_submit_success
  • backup_create_requested
  • backup_file_saved
  • backup_file_save_error
  • restore_open_requested
  • restore_file_selected
  • delete_all_data_confirmed
  • reset_preferences_confirmed
