## 🚀 How to Update Existing Repo

If this is the **first time** applying this comprehensive `.gitignore`:

```bash
# Remove cached files from Git history (without deleting locally)
git rm --cached -r .

# Re-add everything (now respecting new .gitignore)
git add .

# Commit
git commit -m "chore: update .gitignore for KMP project"

# Verify (optional)
git status
```

**⚠️ WARNING**: This will stage all previously ignored files for removal. Verify `git status` before commit.
