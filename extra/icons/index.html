📸 Screenshot Multilingue

Per ogni lingua, cattura 8 screenshot della sequenza:

  • Dashboard - Riepilogo transazioni
  • Aggiungi Transazione - Form di input
  • Categorie - Breakdown spese
  • Grafici - Analisi e trend
  • Scansione Ricevute - OCR feature
  • Impostazioni - Preferenze
  • Backup/Restore - Data management
  • Dark Mode - Theme alternativo

Struttura:

store-assets/screenshots/ ├── it/phone/ (01-08_*.png) ├── en/phone/ (01-08_*.png) ├── de/phone/ (01-08_*.png) ├── fr/phone/ (01-08_*.png) └── es/phone/ (01-08_*.png)

⚙️ Script Automazione

convert_icons.sh

Converte SVG in PNG per tutte le risoluzioni

bash convert_icons.sh
SVG → PNG

capture_screenshots.sh

Cattura screenshot per una o tutte le lingue

bash store-assets/capture_screenshots.sh it
bash store-assets/capture_screenshots.sh --all
Multilingue

optimize_screenshots.sh

Ottimizza/comprime gli screenshot

bash store-assets/optimize_screenshots.sh
Compressione

verify_screenshots.sh

Verifica che tutti gli screenshot siano presenti

bash store-assets/verify_screenshots.sh
Verifica

🚀 Quick Workflow

Fase 1: Generare Icone

cd extra/icons/ bash convert_icons.sh # Output: app-icons/png/*.png pronti per Play Store

Fase 2: Catturare Screenshot

# Per una lingua bash store-assets/capture_screenshots.sh it # Per tutte le lingue bash store-assets/capture_screenshots.sh --all

Fase 3: Ottimizzare

bash store-assets/optimize_screenshots.sh bash store-assets/verify_screenshots.sh

Fase 4: Upload Play Store

1. Accedi: https://play.google.com/console
2. Store Listing → Graphic Assets
3. Carica icone, feature graphic, screenshot per ogni lingua
4. Verifica anteprima → Pubblica

✅ Checklist Pre-Pubblicazione

  • App Icon 512x512 px generato
  • Feature Graphic 1024x500 px generato
  • Screenshot catturati per TUTTE le 5 lingue
  • 8 screenshot per lingua (phone: 1080x1920 px)
  • Screenshot ottimizzati e compressi
  • Verifica completamento eseguita
  • Play Console: Store Listing completato
  • Tutti gli asset caricati (per ogni lingua)
  • Anteprima verificata su Play Console
  • Content rating completato
  • Privacy Policy linkato
  • Pronto per pubblicazione
